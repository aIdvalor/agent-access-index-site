# Agent Access Index

A category-level index of how retail and commerce sites treat AI agents. Logged-out daily check of public policy files, n=160, Oct 31, 2026.

**Finding:** most sites that refuse AI agents publish no policy on them. 53 of 59 refusals (90%) came from sites with no AI-agent rules at the URLs checked.

Dashboard: https://aidvalor.github.io/agent-access-index-site/
